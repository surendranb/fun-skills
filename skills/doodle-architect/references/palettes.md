# Color Palettes & Contrast Contracts

Every doodle SVG must specify a strict color contract in a machine-readable opening comment:

```html
<!-- PALETTE: bg=#... ink=#... primary=#... secondary=#... accent=#... white=#... -->
```

---

## Palette 1: Happy Hues #17 (Editorial Sketchnote — Default)

The standard studio palette: warm, tactile, high contrast, non-fatiguing.

| Token | Hex | Role | Usage |
|---|---|---|---|
| `bg` | `#fef6e4` | Substrate | Cotton-rag parchment canvas |
| `ink` | `#001858` | Pen Ink | Primary line work, text, borders |
| `primary` | `#f582ae` | Wash 1 | Main highlight, focal cards, alerts |
| `secondary` | `#8bd3dd` | Wash 2 | State containers, memory, secondary flow |
| `accent` | `#f4d06f` | Wash 3 | Tokens, badges, stars, key callouts |
| `white` | `#ffffff` | Card Base | Crisp opaque card fills |
