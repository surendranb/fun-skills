# Quality Evaluation & Self-Improving Loop

Sketchnotes are evaluated across three distinct tiers to guarantee high craft, authentic human motor kinematics, and technical clarity.

---

## Tier 1: Deterministic AST Linter (`eval_doodle.py`)

Automated static analysis on the SVG DOM. An illustration fails if any of the following occur:

1. **Palette Contract Violation:**
   - Any fill or stroke uses a hex code not declared in the `<!-- PALETTE: ... -->` header.
2. **Missing Phase Groups:**
   - Must contain at least `phase-1-substrate`, `phase-2-washes`, `phase-4-strokes`, and `phase-6-lettering`.
3. **Layering Inversion:**
   - Translucent washes (`phase-2-washes`) must precede ink strokes (`phase-4-strokes`) in document paint order.
4. **Raw Clip-Art Geometry:**
   - Rejects unstyled `<rect>` or `<circle>` elements that lack hand-drawn path approximations (`<path d="..." />`).
5. **Single Stroke Weight:**
   - Scene must contain at least 2 distinct stroke weight tiers (e.g. bold 3.5px and fine 1.2px).

---

## Tier 2: Visual Perception (Headless Snapshot)

Captures a 2x headless browser render to verify:
1. **No Clipped Text:** Text elements remain within container bounding boxes.
2. **Proper Wash Bleed:** Watercolor washes peek 4–8px outside stroke contours without obscuring text legibility.
3. **Filter Rendering:** GPU shaders compile without SVG filter artifacts.

---

## Tier 3: LLM-as-a-Judge Rubric

Scores the generated illustration on a 1–5 scale across four perceptual axes:

| Axis | Weight | Criterion |
|---|---|---|
| **Cognitive Clarity** | 30% | Can an engineer understand the core system architecture within 3 seconds? |
| **Hand-Drawn Vitality** | 30% | Does it feel genuinely hand-inked on textured paper rather than auto-generated by software? |
| **Visual Metaphor Wit** | 20% | Are abstract ideas anchored by witty, concrete visual iconography (clocks, locks, buckets, conveyor belts, crowns)? |
| **Typography & Hierarchy** | 20% | Is there clean visual pacing between headlines, subtitles, flow labels, and fine detail notes? |
